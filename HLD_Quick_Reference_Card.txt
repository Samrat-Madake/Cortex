================================================================================
IF ASKED ABOUT SPECIFIC BLOCKS
================================================================================

"What's happening in Perception Pipeline?"
→ "Four AI models work together:
   1. YOLO detects all objects
   2. RetinaFace finds faces
   3. RTMPose finds body positions
   4. Speech-to-Text converts audio
   Then we ask ChatGPT to make sense of it all"

"What's the difference between Level 0 and Level 1?"
→ "Level 0 is fast and simple - like asking a friend about photos.
   Level 1 is detailed and accurate - using 4 specialized AI models.
   Level 0 = speed, Level 1 = accuracy"

"What's entity resolution?"
→ "It's how we recognize people.
   We create a unique fingerprint of each person's face.
   If we see the same fingerprint again, we say 'It's the same person!'"

"How does memory work?"
→ "We store observations (raw data) AND facts (learned knowledge).
   Observation: 'Person appeared today at 2 PM'
   Fact: 'This person is a regular visitor'
   We can search and retrieve information instantly"

"What's consolidation?"
→ "Learning from observations.
   After seeing someone 5 times, we learn: 'This is a regular'
   Instead of treating them as unknown person each time"

================================================================================
TRICKY TERMS EXPLAINED SIMPLY
================================================================================

Embeddings:
"Converting something into a unique number code"
Example: Face → [0.234, -0.891, 0.456] = Face fingerprint

Vector Database (Qdrant):
"Database that stores number codes and can find similar codes fast"
Example: Store all face codes, search for similar faces instantly

Re-ID:
"Recognition ID" = Can we recognize if it's the same person?

Semantic:
"Meaningful understanding" = Not just detecting, but understanding meaning

Episodic:
"Event-based" = Recording what happened when (episode 1, episode 2)

Consolidation:
"Summarizing and learning" = Converting observations into knowledge

VLM:
"Vision Language Model" = AI that understands images and language
Examples: ChatGPT, Claude, Gemini

Perception:
"Understanding what's in the image"

Real-time:
"Happening now, not delayed"

Local-first:
"Runs on your device, not in cloud"
